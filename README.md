# Smart Study Planner DSS (UiTM MyStudent Module)

A **Decision Support System (DSS)** module designed for the UiTM MyStudent portal to help students generate personalized, proportional daily study schedules based on academic urgency.

## Features
- **Multi-Criteria Decision Analysis (MCDA):** Calculates objective Priority Scores using the Weighted Sum Model (WSM) based on current grades, exam proximity, and quiz scores.
- **Proportional Time Allocation:** Automatically distributes daily study hours across enrolled subjects with structured rest intervals.
- **Interactive Execution:** Includes an active session countdown timer, task checklists, and progress tracking.
